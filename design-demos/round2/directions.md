# Round 2 · 整体 UI 风格 · 三方向卡

## 共用:品类、调性、标杆与取舍

- **品类**:macOS 桌面对象存储客户端(S3 文件管理器)。品类基线:侧栏导航 + 路径面包屑 + 网格/列表 + 传输队列(Transmit/ForkLift Established)。
- **标杆**:Transmit 5(Panic,官网截图列表 + 产品页文字拆解,2026-10-24 已核实,存 design-demos/refs 计划板未截成)、Raycast(screenrove.com/raycast 逐屏文字拆解,已核实)。其中未能亲眼截图的部分,凭记忆处已在各卡标注。
- **共用取舍**:沿用基线——侧栏 + 工具栏 + 网格 + 悬浮传输队列,用户不用重学;换掉——强调色与材质语言(现状暖橙实物感,来自上一轮已实现的 Panic 方向),这一轮三个方向各换一套色相家族与材质。
- **调性(共用依据)**:工具类、开发者受众、管理自己的媒体资产 → 完成度偏精致、密度中偏密、能量安静到中等;三个方向在严肃度上拉开。
- **品类默认配色**:白/浅灰底 + 蓝强调(Transmit、Finder 一系);上一轮落选了纯黑 Swiss、靛蓝 Linear、红场 Sato——这轮避开这四组。

## 方向 1 · 仪器面板 Graphite Instrument

- **北极星**:一台校准好的测量仪器——冷、准,每个读数都可信。
- **生成引擎**:材质×环境——磨砂铝面板仪器放在工作台上。证据:对象存储客户端本质是"量字节的仪器",用户是开发者。
- **首屏骨架**:用户来看读数和文件。侧栏 + 顶部常驻"读数条"(OBJECTS / SIZE / THROUGHPUT 三块仪表读数,mono 数字)+ 网格;页头一行,首屏第一排内容完整。
- **字体**:system SF(SF Pro);读数与数据 SF Mono;标题细字重大号。
- **色彩**:底石墨 #26282B、面板 #2E3134、文字暖白 #F2F0EB、强调青 #2AA8A0(示波器荧光);派生:选中底 #1F5F5B、描边 #3A3E42、禁用 #55595E。来自:仪器金属 + 荧光读数,非品牌色。
- **主视觉**:读数条——把汇总画成仪表读数,是画面唯一发光处。
- **图标控件语法**:1.5px 白细线图标;控件直角偏小(4px)+ 1px 亮边(倒角高光);LED 圆点状态。
- **结构性突破**:汇总行升级为常驻读数条,数据从"附属信息"变"主角之一"。
- **记忆点**:读数条的三块 mono 数字;LED 呼吸。
- **放弃什么**:暖色、圆角卡片堆叠、渐变。

## 方向 2 · 夜航台 Midnight Emerald

- **北极星**:夜里也不吵的工作台——深而暖,进度自己会发光。
- **生成引擎**:一个具体场景——凌晨一点的书房,台灯下的深色工作毯;光线低、对比柔。证据:开发者夜间长会话管理媒体桶。
- **首屏骨架**:侧栏 + 网格 + 底部整条"光轨"传输栏(占满底边,进度发翡翠光);页头一行。
- **字体**:system SF 暖白;数据 mono;字重层级代替颜色层级。
- **色彩**:底暖黑 #14161A、面板 #1C1F24、文字暖白 #E8E4DA、强调翡翠 #34D399;派生:选中底 #1B3A2E、描边 #2A2E34、禁用 #4A4E55。来自:夜视仪表荧光绿,长看不刺眼。
- **主视觉**:底部光轨——两条传输进度像夜航仪表一样发柔和的光。
- **图标控件语法**:1.5px 线图标;控件圆角 10、双层柔和阴影;进度条带 glow。
- **结构性突破**:传输 dock 从"右下角浮窗"变成"底部整条光轨",进度成为界面的地平线。
- **记忆点**:光轨的辉光;数字增量。
- **放弃什么**:冷蓝紫、高对比纯黑、锐利直角。

## 方向 3 · 施工图 Blueprint

- **北极星**:桶的施工图——一切皆标注,文件长在图纸上。
- **生成引擎**:其他领域的整套表现形式——工程晒图。证据:对象存储就是"结构与位置",key 是路径、bucket 是场地,开发者本来就在图纸上规划文件树;题材有真实联系。此卡为三方向中唯一"用力过头"档。
- **首屏骨架**:图纸幅面——右下角图签(标题栏:桶名/日期/比例),文件网格铺在带方格网的图纸底上,每格带图号(A-01…);页头即图签行。
- **字体**:标注与数据 SF Mono 主导;标题 mono 加粗;中文 PingFang。
- **色彩**:晒图蓝底 #143A66、白线 #EAF2FB、图签橙 #F2A33C(修改标记);派生:选中=双白线框、辅助线 rgba(255,255,255,.14)、禁用 rgba(255,255,255,.35)。来自:晒图纸 + 图签章,题材原生。
- **主视觉**:文件缩略图画成白描线框 + 对角线 + 尺寸标注;真实图片以小窗内嵌。
- **图标控件语法**:全部线框化——按钮白描边、选中双线框、图标 1px 白线;无阴影无填充渐变。
- **结构性突破**:图签 + 图号系统进入网格,每个对象像图纸上的一个图块。
- **记忆点**:右下角图签章;选中时的双线框 + 尺寸标注。
- **放弃什么**:照片直铺、圆角、彩色、阴影。

## 差异检验

- 骨架:读数条+网格 / 底部光轨+网格 / 图纸幅面+图签 — 三种结构。
- 色相家族:石墨+青 / 暖黑+翡翠 / 晒图蓝+白线+橙 — 三个家族,非明暗之分。
- 四项相同数:1 与 2 只共享字体族(system+mono),其余两两不同。
- 极端:方向 3;折中:无超过一个。
- 打破套路:3 的图纸幅面;1 的常驻读数条。
- 与上一轮落选(Swiss 黑白、Sato 红场、Linear 靛蓝、Raycast 键帽)及现状(暖橙)均不撞。
